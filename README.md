# mekotools/turbowarp

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: veröffentlicht wird das fertige Container-Abbild, damit es **ohne
Anmeldung** gezogen werden kann.

- Werkzeug: TurboWarp (Scratch-Oberfläche im Browser, `TurboWarp/scratch-gui`, GPL-3.0)
- Bezug: `docker pull ghcr.io/mekotools/turbowarp:latest`
- Bauvorschrift: interne GitLab-Instanz, `tilllt/mekotools/mekotools-turbowarp-1e08e6a5`
- Die Scratch-Marken gehören MIT und werden hier nicht verwendet.
